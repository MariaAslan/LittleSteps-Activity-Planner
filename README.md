# LittleSteps Activity Planner

LittleSteps is a family activity planner that helps parents organize their children's school events, appointments, activities, and reminders in one place.

## Project Purpose

Parents with multiple children may find it difficult to remember every school event, appointment, lesson, and daily activity. LittleSteps will provide a simple dashboard where parents can manage and view this information.

## Planned Features

- User registration and login
- Create a family group
- Add children to the account
- Add activities with a child, date, time, and optional notes
- Edit and delete activities
- Mark activities as completed
- View today's activities
- View upcoming reminders
- View activities on a monthly calendar

# AI Reflection

## How I Used AI

I used AI as a learning and development assistant while building the LittleSteps Activity Planner.

AI helped me:

- Break the project into smaller tasks.
- Understand PHP, PDO, MySQL, and session-based login.
- Create starting examples for registration, login, activities, reminders, and calendar features.
- Find and fix errors in my PHP files.
- Improve the responsive CSS design.
- Review and test the application features.

## My Contributions

I chose the project idea, planned the features, created the Figma design, built the database, added the project files, tested every feature, and made decisions about the design and functionality.

I reviewed the suggested code, added it to my project, tested it in XAMPP, and corrected problems when the application did not work as expected.

## What I Learned

This project helped me understand:

- How PHP connects to a MySQL database using PDO.
- How registration and login work with sessions and password hashing.
- How to create, read, update, and delete database records.
- How foreign keys connect users, children, activities, and reminders.
- How to display database information in a dashboard and calendar.
- How to use GitHub and GitHub Projects to manage development tasks.

## Challenges

The most challenging parts were connecting the pages correctly, creating secure database queries, and debugging missing files and incorrect links.

Testing each feature separately helped me identify and fix these problems.

## Final Reflection

AI made it easier to understand difficult steps, but I was responsible for building, testing, and verifying the final application. The project improved my confidence with PHP, MySQL, GitHub, and responsive web development.
